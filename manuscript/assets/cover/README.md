# Red Line cover assets

The cover artwork is a generated, text-free editorial substrate. The portrait
asset is used by the PDF title page; the wide asset is reserved for HTML or other
editorial surfaces and is registered as `metadata.editorial_hero_image` in
`manuscript/config.yaml`. Title, subtitle, author, date, and citation text
remain editable renderer output rather than raster text.

## Semantic contract

The red vertical line represents a refusal boundary. The amber pulse represents
an attestation or signal. The separated mark represents a prior copy held outside
the author's write boundary. Teal, blue, ochre, and graphite traces represent
structured work, evidence, situated perspectives, and incomplete knowledge—not
safety scores or empirical measurements. Faded fields and open circles represent
questions that remain unresolved rather than implied permission.

## Provenance

Generated with the Codex image-generation tool on 2026-07-18 from an approved
revision of the paired concept direction. The prompt required a warm archival
paper field, graphite registration marks, a vermilion boundary, an amber signal,
partial evidence traces, open uncertainty fields, and a separated witness mark;
it prohibited words, logos, weapons, surveillance imagery, and generic
cybersecurity motifs. The asset is illustrative; it does not depict an observed
system or measured result. The added texture is editorial rhetoric, not data.
